# 🍹 Saborê - Sistema de Pedidos

Projeto de estudo para criação de um sistema de pedidos online com envio direto para o WhatsApp.

## 🚀 Funcionalidades
- Formulário para captura de **nome, telefone e endereço** do cliente.
- Seleção de produtos com controle de quantidade (+ / -).
- Cálculo automático do **total por item** e **total geral**.
- Envio do pedido formatado para o **WhatsApp** do estabelecimento.

## 🛠️ Tecnologias utilizadas
- **HTML5** para estrutura da página.
- **CSS3** para estilização.
- **JavaScript** para lógica de cálculo e integração com WhatsApp.
- **GitHub Pages** para publicação do site.

## 📦 Como usar
1. Acesse o site publicado via GitHub Pages:  
   👉 [Link do projeto](https://felip39.github.io/Sabore/)  
2. Preencha seus dados no formulário.  
3. Selecione os produtos e quantidades desejadas.  
4. Clique em **Enviar Pedido por WhatsApp**.  
5. O WhatsApp será aberto com a mensagem pronta para envio.
